Effective capacitance:

\[
\frac{c^2}{2c} = \frac{1}{2}c + c = \frac{3}{2}c, \quad c + c = \frac{5}{2}c, \quad \frac{\textcolor{red}{5/2}}{\textcolor{red}{7/2}}c^2 = \frac{5}{7}c
\]

Capacitor current-voltage:

\[
i(t) = C \frac{dv}{dt} \quad \Rightarrow \quad \frac{25 \cos(250t)}{1000} = 3500 \cos(250t)
\]

where \( v(t) = \frac{1}{dt}(14 \sin(250t)) = 3500 \cos(250t) \)

\[
\Rightarrow \quad \frac{25}{1000} = 3500 \cdot \frac{5}{7}c
\]

\[
\Rightarrow c = 1 \times 10^{-5} \, \text{F}
\]

\[
\Rightarrow C = 10 \, \mu\text{F}
