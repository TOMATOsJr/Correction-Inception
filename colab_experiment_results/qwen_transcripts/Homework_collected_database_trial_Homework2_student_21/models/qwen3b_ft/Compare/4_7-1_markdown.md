\[
0.04v_2 = 0.04(50i_1) = 2i_1 = i_2

Solving these equations:

\[
10V + 100(i_1 - i_2) + 50i_1 = 0 \quad \Rightarrow \quad 10V + 150i_1 - 100i_2 = 0
\]

\[
0.04v_2 = 0.04(50i_1) = 2i_1 = i_2 \quad \Rightarrow \quad v_2 = 50i_1
\]

Substituting \( v_2 = 50i_1 \) into the first equation:

\[
10V + 150i_1 - 100(2i_1) = 0 \quad \Rightarrow \quad 10V + 150i_1 - 200i_1 = 0 \quad \Rightarrow \quad 10V - 50i_1 = 0 \quad \Rightarrow \quad i_1 = 0.2A
\]

Thus,

\[
v_2 = 50(0.2A) = 10V
\]
